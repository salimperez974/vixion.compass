# VixiOn Compass

Cuestionario clínico bilingüe (ES/EN) del **Instituto de Ojos de Puerto Rico** que orienta al equipo clínico sobre la vía y el tier (Esencial, Activa, Completa, a la Medida) más apropiados para cada paciente antes de la consulta.

## Demo en vivo

**https://salimperez974.github.io/vixion.compass/**

## Stack

HTML standalone — un solo archivo `index.html` con CSS y JS embebidos. No requiere build ni dependencias.

## Edición

Edita `index.html` directamente. Cualquier `git push` a `main` se publica automáticamente vía GitHub Pages.
